# DeepSeek Balance Widget v0.3.0

本次更新聚焦界面质感、复杂背景下的可读性，以及 Windows 10 / 11 的显示兼容性。

## 主要更新

- 全面重构主悬浮窗、余额曲线和设置窗口，统一为更精致的毛玻璃视觉
- Windows 11 的曲线与设置窗口优先使用 Mica，不支持时自动回退到 CSS 玻璃效果
- 修复主悬浮窗圆角外的矩形底板、阴影裁切和白色背景下的异常方框
- 提高文字、状态信息和操作图标在明暗及复杂背景下的对比度
- 增加键盘焦点、按钮语义、减少动态效果偏好等无障碍细节
- 前端、Rust、Tauri 配置与构建产物统一升级至 `0.3.0`

## 下载说明

- `DeepSeekBalanceWidget_0.3.0_x64-setup.exe`：Windows x64 安装版（推荐）
- `deepseek-balance-widget.exe`：Windows x64 便携版

> 从旧版本升级后若仍看到旧界面，请先从系统托盘彻底退出旧实例，再启动新版本。
